# Do Not Merge Until

1. `cd agent-plugin && npm run validate` has been run in a normal checked-out environment.
2. Root `AGENTS.md` has been reviewed because it becomes persistent coding-agent guidance.
3. At least one read-only routing test and one negative/safety routing test have been exercised in the intended client.
4. Vercel MCP authentication has been connected intentionally; no broad production write permission is required to test the skills.
5. The reviewer confirms the plugin remains additive and does not change `aora-v8-final` runtime behavior.
