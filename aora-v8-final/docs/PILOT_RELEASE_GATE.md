# Aora 8.1.0 Pilot Release Gate

The isolated preview remains Stop-Ship for public sale.

A one-location pilot requires all P0 items to pass with recorded evidence:

- session-derived tenant isolation
- manager location isolation
- durable punch idempotency
- encrypted offline reconciliation
- baseline German work-rule coverage
- invitation activation and replay rejection
- four-role Playwright flows

No merge to `main`, production alias promotion, or production database migration is allowed without explicit approval.
