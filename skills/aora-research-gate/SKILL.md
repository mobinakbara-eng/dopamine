# AORA Research Gate

Follow `agent-plugin/references/research-policy.md`.

## Rules
- Start with AORA implementation and tests; external research cannot tell you what this repository currently does.
- For current libraries/platforms, use official documentation or source as primary evidence.
- For product UX, analyze several competitors and extract patterns instead of copying one interface.
- For security/privacy/accessibility claims, prefer standards and vendor primary guidance.
- Record dates when freshness matters.
- If sources conflict, surface the conflict and choose based on applicability/evidence, not convenience.

## Output to downstream skills
Produce a concise evidence packet containing: problem, current AORA behavior, relevant findings, alternatives considered, rejected patterns, recommendation, confidence and open uncertainties.
