# AORA Competitor Research

Use current public evidence and `aora-research-gate` for material decisions.

For each relevant competitor capture:
- target actor and problem
- workflow entry point
- steps/click burden
- defaults and automation
- permission model
- mobile behavior
- empty/error/recovery behavior
- reporting/audit behavior
- strengths
- friction/risks

Do not copy branding, proprietary text or pixel layout. Synthesize the smallest set of principles that improves AORA's user problem. Explicitly list at least one pattern not worth copying and why.
